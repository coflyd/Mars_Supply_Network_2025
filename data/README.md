# Fonts

The program loads `data/arial.ttf` at startup (path relative to the repository root).
Arial is a proprietary font and is not redistributed here.

To run the current version, copy any TrueType font to that path, for example:

```bash
cp /System/Library/Fonts/Supplemental/Arial.ttf data/arial.ttf   # macOS
```

The upcoming raylib version will use raylib's built-in font or an open-licensed font (OFL).
